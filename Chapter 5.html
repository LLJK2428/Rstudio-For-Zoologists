Chapter 5 - Parametric Tests

What is a parametric test?

A parametric test is a method of statistical analysis that uses the distribution of your data to make assumptions about relationships between your data points. They assume the data follow the aforementioned bell-shaped distribution and use means and standard deviations.

These tests work by assuming the data follow a normal distribution. The word ‘parametric’ comes from ‘parameters’ and reflects these tests’ reliance on distribution shape to function properly. The benefit of these tests is that, because they assume a specific shape, they can extrapolate more information from your data, but if your data fails to meet these assumptions, the tests will not provide sufficiently accurate results.

Note

The Key assumptions:

  1. Normality – Data should be normally distributed, bell-shaped curve.

  2. Equal Variance – Data should have approximately equal variance. (can be calculated from summary stats)

  3. Independence – Data should be randomly and independently sampled.

  4. No Outliers – There should be no extreme outliers.

T-test

A t-test uses the means and variance betweendata points to test for significance, either against an expected value or between independent groups; there are two commonly used T-tests (One-sample and two-sample).

One sample T-test

This version takes one group of data and tests the mean against an expected value to determine whether the result is statistically significant.

For example, someone has said that Blackbirds in the UK have an average weight of 85g. Obviously, we cannot sample the entire population of blackbirds in the UK, so we use a sample, and the t-test tells us whether our sample is statistically consistent with the literature value.

To use R, we can use the function shown below. Our expected value goes alongside ‘mu =’.

blackbird_weights = c(88,89,87,93,95,99,93,95,91,91,90,94,94,95,92,91,88,89,88,89)

t.test(blackbird_weights, mu = 85)

    One Sample t-test

t = 9.2888, df = 19, p-value = 1.704e-08
alternative hypothesis: true mean is not equal to 85
95 percent confidence interval:
 90.0741 93.0259
sample estimates:
mean of x 
    91.55
TipUnderstanding the output

As you can see there has been 3 values at the top which will be most important to us, t, df, and the p-value.

Output Meaning
t This is the t test value
df Degrees of freedom, N-1
p This value is created from the last two, its what we will use to test for significance

So, we know our value of significance, which is alpha (α = 0.05), and we have had our p-value outputted from our test, this is what we need to see if there is significance in our data. In this case, as ‘p < α = 0.05’ , there is a significance in our data. So we would REJECT our null hypothesis

Two sample T-test

A two-sample t-test is similar to the one-way in the sense that you get similar outputs and that it works by looking at variance between data points and means; however, you do not use it against an expected value; it’s used between two independent groups.

For example, we could look at the weight of blackbirds in urban areas and woodlands; we want to see if there is a difference, so we use this test to see if the difference is significant in our sample.

Urban <- c(95,90,91,97,89,86,87,93,91,89)
Woodland <- c(84,84,85,83,87,85,83,82,86,85)

t.test(Urban, Woodland, var.equal = TRUE)

t = 5.409, df = 18, p-value = 3.865e-05

Analysis of Variance (ANOVA)

ANOVA is a method used to determine significant differences between the means of three or more groups by comparing variability within and between groups. However, ANOVA will not necessarily tell you which group is most significant, so you will need to perform a post hoc test afterwards. The post hoc test will compare the results against each other to see which is most significant. There are a few different ANOVAs you can run, but for this guide I’ll show you the One-way and the Two-way.

For a bit of terminology to help you understand it better:

A factor variable is what is being changed, so for instance, light intensity on a crop, or frequency of watering.

A response variable is what you measure, such as plant height.

One-way ANOVA

A one-way ANOVA is to be used when you have ONE FACTOR VARIABLE contributing to your response variable. For instance, we measure weight gain in birds from 3 different seed mixes. The bird seed mix is our factor variable, and weight will be our response variable. The problem with ANOVA is that it doesn’t tell you which group is most significant; to figure this out, we also need to run a Post hoc test.

The Syntax for the ANOVA is as follows:

aov(NAME OF RESPONSE VARIABLE ~ NAME OF FACTOR VARIABLE, data = NAME OF DATA)

I’ve created a dataset that simulates the results of this experiment:

birds <- read.csv("BDowanova.csv")

result <- aov(WeightGain ~ Mix, data = birds)

summary(result)

Residuals   42  13.34    0.32

As you can see there has been 3 values at the top which will be most important to us; f, df, and the p-value.

Output Meaning

You’ll notice that you’ve only got 1 p-value, so next we need to perform the Post hoc in order to decipher the significance between the groups.

TukeyHSD(result)

TipUnderstanding the output

For this, we need to look at the ‘diff’ column; this is the comparison across groups. So, from these results, we can see: Mix B showed a greater weight gain than Mix A by 3.7. Mix C showed less weight gain than Mix A by -2.17. Mix C showed less weight gain than Mix B by -5.87

So the ranking of groups would be:

Mix B – highest weight gain; Mix A – intermediate weight gain; Mix C – lowest weight gain

Furthermore, you will see that you have a ‘p adj’ value; this is the p-adjusted value. At the moment it’s reported as 0; in reality, it’s a very small number. The important thing is that it’s below 0.05, which indicates that the seed mixes differ significantly.

TipReporting the results

Now that you have all of your values, you will need to report them in text form, which you can do like this:

One-way ANOVA “A one-way ANOVA was conducted to determine whether seed mix affected the weight gain of birds (n = 45). There was a statistically significant effect of seed mix on their weight gain, F(2,42) = 416.5, p > 0.001. From this, we noted that the weight gain significantly differed among the three seed mixes.”

Tukeys Post hoc

Following a significant one-way ANOVA, we conducted a Tukey HSD post hoc test to determine group differences. Birds fed Mix B gained significantly more than birds fed Mix A (mean difference = 3.7g, p < 0.001) and Mix C (mean difference = 5.87, p < 0.001). Birds fed Mix A also gained significantly more weight than birds fed Mix C (mean difference = 2.17g, p >0.001). Therefore, all three seed mixes produced significantly different results, with Mix B averaging the greatest weight gain.

Two-way ANOVA

A two-way ANOVA is used when you have two factor variables that may influence a single response variable. For instance, we may measure weight gain in birds fed three different seed mixes while also investigating whether weight gain differs between males and females. In this example, seed mix and sex are the two factor variables, while weight gain is the response variable.

The Syntax for the ANOVA is as follows:

aov(NAME OF RESPONSE VARIABLE ~ FACTOR VARIABLE 1 * FACTOR VARIABLE 2, data = NAME OF DATA)

Ive created a dataset that simulates the results of this experiment:

birds <- read.csv("BD2wanova.csv")
RESULTS <- aov(WeightGain ~ Mix * Sex, data = birds)

summary(RESULTS)

Residuals   39  12.22    0.31                   
---

“A two-way ANOVA showed a statistically significant effect of seed mix on bird weight gain, F(2, 39) = 422.23, p < .001. However, there was no statistically significant effect of sex on weight gain, F(1, 39) = 3.10, p = .086, and no significant interaction between seed mix and sex, F(2, 39) = 0.24, p = .790.”

Pearson’s Correlation

Pearson’s correlation tests whether a linear relationship exists between two continuous variables; this relationship can be negative or positive. Examples include temperature and insect abundance, Rainfall and Plant growth, and Bird Body Mass and Wing length.

When you perform the test, you will receive a value called the correlation coefficient (r). This value will always be between -1 and 1 and will indicate the type of relationship your data has:

r value Interpretation
+/-1 Perfect +/- correlation
+/-0.8 Strong +/- correlation
+/10.5 Moderate +/- correlation
+/-0.2 Weak +/- correlation
0 No correlation
TipAssumptions
  • Both variables are continuous
  • The relationship is linear
  • There are no major outliers
  • Data will be somewhat normally distributed

If these assumptions are not met you will want to perform a spearmans rank instead

The syntax for this test is very simple:

cor.test(VARIABLE NAME 1, VARIABLE NAME 2, method = “pearson”)

Here, we will use fake data to see whether there is a correlation between bird Wing length and Body mass. A good idea when doing a linear relationship group would be to plot the data to visualise the relationship.

birds <- read.csv("fakebirdD.csv")

library(ggplot2) #See chapter 3b for how to use ggplot

ggplot(birds, aes(x = WingLength_mm,
                  y = BodyMass_g )) +
  
  geom_point(size = 3,
             shape = 24) +
  
  geom_smooth(method = "lm", se = TRUE, colour = "red") +
  
  theme_classic()+
  
  labs( x = "Wing Length (cm)",
         y = "Weight (g)",
         title = "Relationship between wing length and body mass")
`geom_smooth()` using formula = 'y ~ x'
cor.test(birds$WingLength_mm,
         birds$BodyMass_g,
         method = "pearson")

TipReporting the results

Pearson’s correlation analysis revealed a statistically significant, strong positive correlation between wing length and body mass, r(198) = 0.985, p < 0.001
